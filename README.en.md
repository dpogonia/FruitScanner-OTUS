# Fruit Scanner

Fruit recognition and a face edit. An OTUS study project.

## What it does

The Fruits tab recognizes apple, avocado, banana, cherry, kiwi, mango, orange, pineapple, strawberry, and watermelon. A picture can come from the photo library, the camera, or AR. When the model is confident, the screen shows the name and the percent.

The Editor tab finds a face in a photo and warps it.

## Stack

SwiftUI, Vision, CoreML, ARKit, AVFoundation.

## Run

```bash
git clone https://github.com/dpogonia/FruitScanner-OTUS.git
cd FruitScanner-OTUS
open MLAppOTUS.xcodeproj
```

Run the **MLAppOTUS** scheme on an iPhone simulator. The camera and AR need a device.
